# wiki_fetcher - 中文维基百科批量抓取工具

使用 MediaWiki Action API 批量抓取维基百科页面的结构化数据。

## 功能

从 `targets.txt` 读取词条列表，支持分类注释，批量抓取并保存 3 份 JSON 文件：

| 文件 | 内容 | 用途 |
|------|------|------|
| `*.parse.json` | 渲染 HTML、sections、links、images、categories | RAG 文本处理 |
| `*.imageinfo.json` | 图片 URL、MIME、尺寸 | 多模态方案 |
| `*.pageprops.json` | wikibase_item 等属性 | KG 实体对齐 |

## 安装依赖

```bash
uv add requests
```

## 使用方法

### 1. 编辑 targets.txt

在 `scripts/wiki_fetcher/targets.txt` 中配置需要抓取的词条：

```
// 元信息
岸本齐史

// 角色
漩涡鸣人
宇智波佐助

// 概念
尾獸
血继限界
查克拉_(火影忍者)

// 作品
火影忍者
```

**格式规则：**
- 空行：自动忽略
- `// 开头`：分类注释，影响后续词条的存储路径
- 其他行：词条名称（与维基百科页面标题完全一致）

### 2. 运行抓取

```bash
uv run scripts/wiki_fetcher/main.py
```

程序将自动读取 `targets.txt`，批量抓取所有词条，并保存到分类目录中。

## 输出结构

```
data/raw/wiki/
├── 元信息/
│   └── 岸本齐史/
│       ├── parse.json
│       ├── imageinfo.json
│       └── pageprops.json
├── 角色/
│   └── 漩涡鸣人/
│       ├── parse.json
│       ├── imageinfo.json
│       └── pageprops.json
└── 概念/
    └── 尾獸/
        ├── parse.json
        ├── imageinfo.json
        └── pageprops.json
```

每个词条都有自己的独立目录，按分类组织。**所有词条目录中的文件名完全一致**，便于系统统一读取。

## 配置常量

所有配置都在 `main.py` 中定义，无需命令行参数：

| 常量 | 默认值 | 说明 |
|------|--------|------|
| `TARGETS_FILE` | `./targets.txt` | 词条列表文件路径 |
| `OUTPUT_BASE_DIR` | `data/raw/wiki` | 输出根目录 |
| `WIKI_LANG` | `zh` | 维基百科语言代码 |
| `IMAGEINFO_BATCH_SIZE` | `40` | ImageInfo 批量请求大小 |
| `DEFAULT_CATEGORY` | `未分类` | 默认分类名称 |

## 特性

- ✅ 批量抓取，自动处理所有词条
- ✅ 分类组织，支持 `//` 注释定义分类
- ✅ 统一文件命名，所有词条目录使用相同的文件名（`parse.json`、`imageinfo.json`、`pageprops.json`）
- ✅ 防重复抓取，自动跳过已存在完整数据的词条
- ✅ 健壮的错误处理，单个词条失败不影响其他词条
- ✅ 自动重试机制，网络异常自动重试（最多 3 次）
- ✅ 请求限流，遵守维基媒体 API 使用规范
- ✅ 跨平台文件名处理，安全的文件命名
- ✅ 详细的进度显示和统计信息
